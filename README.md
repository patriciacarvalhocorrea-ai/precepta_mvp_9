# PRECEPTA Landing V3

Protótipo responsivo baseado no Brand & Product Positioning Charter aprovado e nos assets canônicos enviados.

## Páginas
- `index.html` — landing
- `login.html` — exemplo de login
- `cadastro.html` — exemplo de cadastro em 3 etapas

## Publicação
Pode ser publicado como site estático em GitHub Pages.
Os formulários são demonstrativos e ainda não possuem backend/autenticação real.

## Assets
Todos os recortes usados neste protótipo foram derivados apenas dos boards canônicos enviados nesta conversa.
