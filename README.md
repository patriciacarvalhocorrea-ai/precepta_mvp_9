# PRECEPTA Landing Prototype v2

Protótipo estático responsivo para teste em GitHub Pages.

## O que mudou nesta versão
- Header usa a **logo raster canônica aprovada** como asset, em vez do placeholder tipográfico.
- Hero e seção de preceptores usam o **group art canônico aprovado** com Dr. Caio, Dra. Ana, Dra. Sofia, Dr. Sebastião, Dra. Helena e Dra. Yoko.
- Crop e posicionamento foram ajustados separadamente para desktop, tablet e celular.
- Não há dependência de Figma.
- Enquanto o SVG mestre não existir, esta versão raster é a referência visual correta para o protótipo.

## Estrutura
- `index.html`
- `styles.css`
- `assets/precepta-logo-primary-canonical.png`
- `assets/precepta-team-canonical.jpg`

## Teste local
Abra `index.html` no navegador.

## GitHub Pages
1. Envie o conteúdo desta pasta para a raiz do repositório.
2. Settings → Pages.
3. Publique a branch desejada a partir de `/ (root)`.

## Observações
- CTAs ainda são demonstrativos.
- A menção ao Enamed não afirma certificação ou alinhamento formal.
- O raster da logo é provisório apenas no sentido técnico: **o desenho visual usado é o aprovado**. Futuramente poderá ser substituído pelo SVG mestre sem mudar a identidade.
